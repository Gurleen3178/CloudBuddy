# ☁️ CloudBuddy – Your Cozy Weather Companion

CloudBuddy is a modern, user-friendly weather web application designed to make checking the weather simple, informative, and enjoyable.

Built using **HTML, CSS, and JavaScript**, CloudBuddy provides real-time weather updates, a 5-day weather forecast, and an AI-powered chatbot that helps users understand weather conditions and answer weather-related questions.

### ✨ Key Features
- **Live Weather Updates:** Get current weather information for your searched city.
- **5-Day Forecast:** View upcoming weather conditions.
- **AI Weather Assistant:** Interact with a friendly AI chatbot powered by Groq.
- **Weather Insights:** Get helpful answers based on current weather conditions.
- **Responsive Interface:** A cozy, visually appealing design for a pleasant user experience.

### 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
- Groq API

### 🎯 Project Goal
The goal of CloudBuddy is to combine real-time weather information with artificial intelligence to create an interactive and approachable weather experience.

### 👩‍💻 Developer
Created as a personal learning project to explore frontend web development, API integration, JavaScript, and AI-powered applications.
